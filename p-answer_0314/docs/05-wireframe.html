1 ワイヤーフレーム作成方法

作成方針 現行HTMLの画面構成と `md/香りワークショップ_PC問_ワイヤーフレーム_更新版.md` をもとに、役割が分かる単位で整理する。

2 トップページ

トップページ ワイヤーフレーム（PC版） 必須
[Header] Brand / CTA
[Hero] コピー / リード / CTA / プレビュー
[Flow] 3ステップ説明
[Preview] アンケート画面 / グラフ画面の先見せ
[Value] 体験価値説明
[Reassurance] 安心材料 / FAQ
[Final CTA] アンケート開始 / 予約
配置意図の説明 必須

最上部で「あなたに合う香りを知る」という期待を作り、その直後にCTAを置く。中段では流れとプレビューを見せて不安を減らし、下段で体験価値と安心材料を補強して予約導線に戻す構成とした。

3 下層ページ

下層ページ ワイヤーフレーム 必須
[Question Layout]
Left: 質問ナビ
Center: タイトル / 補足文 / 3択カード / 中立選択肢
Right or Footer: 豆知識 / 補足説明
Bottom: 次への導線

[Graph Layout]
Left: レーダーグラフ
Right: スライダー / プリセット / CTA

[Reservation Layout]
Left: 回答傾向
Center: 予約枠 / 入力項目
Bottom: スタッフメモ / 確定ボタン
