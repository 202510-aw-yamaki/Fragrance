## 今回までの実施内容
### 1. ヘッダーロゴ差し替え
- PC / 中間幅では `img/TOP/roherarogo.png` を使用する形へ変更した。
- SP幅では `img/TOP/吟ロゴ.png` に切り替えるよう `picture` 要素で分岐した。

### 2. SPヘッダーの構造見直し
- `header-top` はロゴのみを持つ構造へ整理した。
- `header-actions` に `回答する`、`予約する`、ハンバーガーメニューをまとめた。
- SP幅では `ロゴ（左）` と `回答する / 予約する / ハンバーガー（右）` の 1 ロウ構成を前提に調整した。
- `header-inner` に残っていた `flex-direction: column` を解消し、`row` ベースで動くように修正した。

### 3. CTA 表示崩れの調整
- SP幅で CTA ラベルがはみ出す問題を調整した。
- ボタンの高さ、余白、フォントサイズ、`line-height` を見直した。
- `label-default` / `label-short` の同時表示で `回答する回答`、`予約する予約` になっていたため、通常SPでは `回答する` / `予約する`、狭幅だけ `回答` / `予約` に切り替えるルールを整理した。

### 4. ヘッダーナビ文言の復旧
- 構造調整時にヘッダーナビが英語 (`Flow` / `Question` / `Value` / `Info` / `FAQ` / `Reserve`) へ置き換わっていたため、日本語 (`流れ` / `質問` / `価値` / `情報` / `安心` / `お願い`) に復旧した。
- この件は重要インシデントとして別記録にも追記した。

### 5. 基本情報エリアの高さ調整
- `#information` の高さは左カラム単独ではなく、中央 / 右カラムを含めた 3 カラム全体の最も高い列に引っ張られる構造であることを確認した。
- 開発者ツール上で良かった状態に合わせ、`.info-middle, .info-right` の `display: grid;` を一度外した。
- その後、右カラムだけは `info-station` と地図を 1:1 で並べたい要件に合わせ、`.info-right` のみ `display: grid; grid-template-rows: 1fr 1fr;` に変更した。

## 現時点の見立て
- 基本情報エリアの高さは、左看板画像だけが原因ではない。
- 中央カラムの縦積み要素と、右カラムの駅画像 + Google Map が高さに強く影響している。
- そのため、セクション全体へ雑に `max-height` を入れるより、各カラムの高さ要因を個別に調整する方が安全。
