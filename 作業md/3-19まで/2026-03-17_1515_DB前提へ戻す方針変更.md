# 2026-03-17 15:15 DB前提へ戻す方針変更

## 1. 対象
- src/main 配下の Spring Boot / Thymeleaf 側
- Fregrance フォルダ直下の静的フロントは対象外

## 2. 背景
- 直前までは「DB 未設定でも起動すること」を優先し、FregranceApplication で DataSource / MyBatis の自動構成を一時除外していた
- ユーザー判断として、src/main 配下の Thymeleaf 側は DB 前提に戻してよい方針へ変更
- ルート直下の静的フロントはそのまま維持する

## 3. 実施内容
- FregranceApplication の一時除外を解除し、通常の @SpringBootApplication に戻した
- これにより、今後の src/main 側は DB 接続設定を前提に進める

## 4. 注意点
- この変更後は、Spring Boot 起動には DB 設定または代替設定が必要
- ルート直下の index.html など静的ページ群には手を入れない

## 5. 次アクション
- DB 接続設定をどう入れるかを決める
- 予約 / アンケート結果 API を DB 前提でつなげる
