## 8. MySQL 導入が許可された場合の次アクション
- ローカル MySQL を導入
- `application.yml` に `spring.datasource.*` を設定
- `spring-boot:run` で起動確認
- `schema.sql` / `data.sql` の反映確認
- `reservation` / `questionnaire-results` API を DB 前提で接続確認
- その後、フロントの `sessionStorage` 依存を段階的に API へ置き換える

## 9. H2 に切り替える場合の次アクション
- `pom.xml` の依存関係見直し
- `application.yml` を H2 用に変更
- schema / data がそのまま使えるか確認
- API 疎通確認後、フロント連携へ進む
