## 前提メモ
- このプロジェクトは Spring Boot + Maven のローカルプロジェクトである
- MySQL はローカルに導入済みで、ローカル起動確認済み
- `application.yml` は MySQL 接続と `PORT` 環境変数に対応済み
- `/` はすでにトップページへ到達するため、`/todo` リダイレクトは不要
- `./mvnw.cmd test` は成功済み
- `docker build -t fregrance-app .` は成功済み
