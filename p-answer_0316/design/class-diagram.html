パッケージの役割 必須

Spring Boot 実装時は、画面返却、API、業務ロジック、永続化、認証、バリデーションを分離する。既存の静的HTMLにあるインライン処理を責務別に移し替えることで、予約保存やスタッフ閲覧を安全に追加できる構成にする。

2 Entity（エンティティ）

Task.java 必須

`Task.java` 相当は予約本体を表す `Reservation.java` とする。

Reservation
- Long id
- String reservationCode
- LocalDateTime reservedAt
- Integer guestCount
- String visitPurpose
- String customerMemo
- String routeType
- String status
- Long slotId
- LocalDateTime createdAt
- LocalDateTime updatedAt
User.java 必須

`User.java` 相当は管理画面利用者を表す `StaffUser.java` とし、公開側ユーザーは匿名利用のため保持しない。香りに関する来店前情報は `QuestionnaireAnswer` と `FragranceProfile` に保持する。

StaffUser
- Long id
- String loginId
- String passwordHash
- String displayName
- String role

QuestionnaireAnswer
- Long id
- Long reservationId
- String questionCode
- String answerCode
- Integer answerOrder

FragranceProfile
- Long id
- Long reservationId
- Integer floralScore
- Integer freshScore
- Integer woodyScore
- Integer spicyScore
- Integer sweetScore

6 クラス間の依存関係

依存関係図 必須

      |
      v

StaffReservationController --> ReservationService

DI（依存性注入）の仕組み 任意

各 Controller は必要な Service のみを、各 Service は必要な Repository のみをコンストラクタインジェクションで受け取る。依存の向きを固定することでテストしやすくし、静的プロトタイプから業務アプリへ移行しやすい構成にする。
