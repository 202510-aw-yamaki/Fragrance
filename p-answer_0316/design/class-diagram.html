パッケージの役割 必須

Spring Boot 実装では、画面返却、REST API、業務ロジック、MyBatis Mapper、認証、バリデーションを分離する。既存の静的HTMLの責務を安全に移し替えるため、Service に業務処理、Mapper に SQL、DTO / Form に入出力定義を寄せる。

2 Model / DTO

Task.java 必須

`Task.java` 相当は、MyBatis で扱う予約モデル `ReservationModel.java` とする。

ReservationModel
- Long id
- String reservationCode
- LocalDateTime reservedAt
- Integer guestCount
- String visitPurpose
- String customerMemo
- String routeType
- String status
- Long slotId
- LocalDateTime createdAt
- LocalDateTime updatedAt
User.java 必須

`User.java` 相当は管理画面利用者を表す `StaffUserModel.java` とし、公開側ユーザーは匿名利用のため保持しない。来店前情報は `QuestionnaireAnswerModel` と `FragranceProfileModel` に保持する。

StaffUserModel
- Long id
- String loginId
- String passwordHash
- String displayName
- String role

QuestionnaireAnswerModel
- Long id
- Long reservationId
- String questionCode
- String answerCode
- Integer answerOrder

FragranceProfileModel
- Long id
- Long reservationId
- Integer floralScore
- Integer freshScore
- Integer woodyScore
- Integer spicyScore
- Integer sweetScore

StaffReservationController --> ReservationService

DI（依存性注入）の仕組み 任意

各 Controller は必要な Service のみを、各 Service は必要な Mapper のみをコンストラクタインジェクションで受け取る。依存の向きを固定することでテストしやすくし、MyBatis ベースの業務アプリへ移行しやすい構成にする。
